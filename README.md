# 반짝 놀이터

한글·수학·영어 놀이 1,500문제와 별이 꾸미기 사이트입니다. 기본 놀이, 7살 도전, 8살 도전에 각각 500문제씩 있습니다. 각 난이도는 100단계이며, 한 단계마다 5문제씩 놀이합니다. 회원 가입은 필요하지 않습니다.

휴대폰에서 바로 열기: [반짝 놀이터](https://sungkue.github.io/banjjak-playground/)

## 실행

Windows에서는 `start-site.cmd`를 실행한 뒤 브라우저에서 [http://localhost:4173/](http://localhost:4173/)을 여세요. 또는 이 폴더에서 터미널을 열고 다음 명령을 실행하세요.

```powershell
python -m http.server 4173
```

서버를 종료하려면 터미널에서 `Ctrl+C`를 누르세요.

별, 끝낸 단계, 스티커, 선택한 난이도, 옷과 배경 선택은 이 브라우저에 저장됩니다. 기존 진행 기록도 이어집니다. 각 과목의 단계는 앞 단계를 마치고 별을 모으면 열립니다. 7살 도전은 별 75개와 기본 놀이 10단계 완료, 8살 도전은 별 200개와 7살 도전 15단계 완료가 필요합니다. 두 난이도 조건의 단계 완료는 어느 한 과목에서 달성하면 됩니다.

한 판에는 5문제와 작은 탐험 목표가 있습니다. 아이는 힌트를 먼저 보거나, 수학 그림을 하나씩 세고, 한글 문장을 나눠 읽고, 영어 보기의 소리를 정답 선택 전에 들을 수 있습니다. 첫 오답에는 풀이 단서, 두 번째 오답에는 정답 설명이 나옵니다. 정답 뒤에도 다른 보기를 눌러 비교할 수 있습니다. 한 판을 마치면 보기 없이 먼저 답을 떠올리는 기억 카드에 도전하고, 모은 성취는 스티커북에서 볼 수 있습니다. 별은 문제당 한 번만 받으며, 다시 놀 때 보기 순서를 섞습니다.

음악은 첫 화면 터치 후 시작하며 3곡이 번갈아 나옵니다. 정답·재시도·단계 완료·꾸미기에 각기 다른 효과음이 나옵니다. 오른쪽 위 스피커로 음악·음성·효과음을 한꺼번에 끄거나 켤 수 있습니다. 음성, 그림, 글꼴은 사이트에 포함되어 있어 외부 서비스가 필요하지 않습니다.

문제 데이터 확인: `node check.mjs` 또는 `npm run check`
